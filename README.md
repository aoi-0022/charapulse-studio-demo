# CharaPulse Studio — UI demo

Windows アプリ「CharaPulse Studio」ver.1.0.0 の画面紹介です。

専用Portable環境の準備画面と4つの制作工程を切り替え、画面の拡大と明暗テーマの切り替えを試せます。画像生成・ファイル操作・ComfyUI接続は行いません。候補画面には提供された2枚の生成作例を掲載しています。作例は生成品質やキャラクター同一性の保証ではありません。

このフォルダは、表示用HTMLと同梱ライブラリ通知の静的書き出し記録です。製品本体・製品ソース・モデル・利用者設定・認証情報は含みません。

## 用途

`index.html` は画像を内包し、追加の画像ホスティングや生成APIを必要としません。販売者の手元で表示確認に使います。

GitHub Pagesは商取引促進を主目的とする利用への公式制限があるため、BOOTHへの販売導線には使いません。更新時は検証済みの `index.html` と `THIRD_PARTY_NOTICES.txt` を一緒に置き換え、個人情報や未公開ファイルを追加しないでください。
